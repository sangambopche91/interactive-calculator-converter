# Interactive Calculator & Unit Converter

## Project Overview
This project is a menu-driven command-line application developed using Python. It performs basic arithmetic operations and converts common units.

## Features
- Addition, subtraction, multiplication, and division
- Division-by-zero handling
- Kilometres to miles conversion
- Celsius to Fahrenheit conversion
- Kilograms to pounds conversion
- Input validation using loops and exception handling
- Repeating menu until the user chooses to quit

## Requirements
- Python 3.10 or newer
- No external packages required

## How to Run
1. Install Python 3.10 or newer.
2. Open a terminal in the project folder.
3. Run `python calculator.py`.

## Concepts Used
Functions, conditional statements, while loops, user input, type conversion, and try/except exception handling.
